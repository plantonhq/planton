# GKE fleet kinds and the Compute image: capabilities the console asked for that need more than text

**Area**: `catalog/gcp/gcpgkefleetfeature`, `gcpgkefleetscope`, `gcpcomputeimage`.
**Type**: feature.

## What is asked

- **Explicit "off" choices on a fleet feature:** each fleet-wide off value modeled as an arm the provider can send, rather than an unset field.
- **A membership's project on features and scopes:** both modules carry the membership's project (or refuse a cross-fleet membership); a literal CEL rule risks refusing valid paths written with a project number.
- **An image deprecation lever** (`deprecated` state, replacement, dates).
- **Image permissions:** a raw-disk import reads the Cloud Storage object, and a customer-managed key needs Compute Engine's service agent granted on the key; `permissions.yaml` names neither.

Source: the console team's notes of 2026-10-24 (GKE fleet; worker pool and image).
