# Six providers' e2e processes leave their Pulumi backend, and the keys in it, on disk

**Area**: `e2e/aws`, `e2e/azure`, `e2e/cloudflare`, `e2e/digitalocean`, `e2e/auth0`, `e2e/e2e_test.go`.
**Type**: bug.

## What is broken

Each of these `TestMain`s creates a temporary Pulumi backend with `os.MkdirTemp`, then `defer os.RemoveAll(backendDir)`, then ends with `os.Exit(code)`. `os.Exit` skips deferred calls, so the backend is never removed. A lane's stack state holds the provider configuration it ran with, credentials included, so every run leaves those credentials in plain text in `$TMPDIR`.

The GCP process had the same defect. About 70 of its backends had piled up in one operator's `$TMPDIR` and held every lane identity's key. It is fixed in `e2e/gcp/gcp_test.go`: `TestMain` is `os.Exit(runLanes(m))`, and the work, with its deferred cleanup, lives in `runLanes`.

## What is asked

Apply the same shape to the six `TestMain`s, so the deferred removal runs on every exit path, early failures included.
