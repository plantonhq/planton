# Managed Kafka kinds: capabilities the console asked for that need more than text

**Area**: `catalog/gcp/gcpmanagedkafkacluster`, `gcpmanagedkafkatopic`, `gcpmanagedkafkaacl`, `gcpmanagedkafkaconnectcluster`, `gcpmanagedkafkaconnector`.
**Type**: feature.

## What is asked

- **Children derive their project and location from the resolved parent:** a topic, ACL or connector whose parent is a reference takes the project and location the spec states, not the parent's; the modules (or a module precondition) should derive or check them from the resolved path.
- **"No retries" on a connector:** the provider lacks `task_retry_disabled`, so a connector cannot say it.
- **Connect `secretPaths`:** absent from the provider.
- **The cluster's bootstrap address as an output:** pulumi-gcp v9.37 lacks it; it lands with the provider upgrade already filed.
- **An ACL rule tying each operation to the resource types Kafka allows it on.**

Source: the console team's note of 2026-10-19 (Managed Kafka, five kinds).
