# Provider parity records the Terraform provider version Pulumi bridges

**Area**: `pkg/providerparity`.
**Type**: feature.

## What is asked

The parity baseline reads Google's provider schema at the version the Terraform modules pin (`~> 8.3`), while Pulumi bridges its own Terraform provider version (pulumi-gcp v9.37.0 today). An argument that exists only in 8.x passes the parity gate yet is missing on Pulumi. The tooling should record the bridged version beside the baseline and flag arguments that only the newer provider carries.

Source: the console team's Managed Kafka note of 2026-10-19 (item 8).
