# A GKE cluster with workload logging never enables the Cloud Logging API

**Area**: `catalog/gcp/gcpgkecluster` (both engines enable only `container.googleapis.com`)
**Type**: bug. Handed by the burn-down of every reported issue (2026-09-25, Harsha's H14-4).

## What a platform engineer sees

A `GcpGkeCluster` that turns on workload logging deploys, but its logs never arrive, because the project's Cloud Logging API is never turned on. Monitoring is the same.

## Fix

When logging or monitoring is on, both modules enable `logging.googleapis.com` (and `monitoring.googleapis.com`), the way every kind enables the APIs it uses, and the permission manifest's API group covers it. The GCP proof lane re-proves the cluster in its session 3 (Q02) and lands this there.
