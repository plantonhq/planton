# Preset docs: phantom "Placeholders to Replace" rows — fleet-wide content pass

A scripted sweep found **76 presets across providers** (AWS, GCP, Azure,
Cloudflare, AliCloud, and others) whose markdown "Placeholders to Replace"
table lists at least one `<placeholder>` that does **not** appear in the
preset's own `yamlContent`. Users are told to replace something that is not
there.

The Azure NSG trio (`azurenetworksecuritygroup/v1/presets/01–03`) was fixed
on 2026-07-21 by deleting the phantom `<your-nsg-name>` row — the sibling
convention (e.g. the azurepublicip presets) is a hardcoded example name in
the YAML with no placeholder row for it. Do NOT fix by parameterizing the
YAML: an angle-bracket value in `yamlContent` breaks console wizard preset
hydration against field-format validation.

## Why this is a deliberate content pass, not a bulk regex

Each hit needs case-by-case judgment:

- Some rows are true phantoms (the NSG class) — delete the row.
- Some are **instruction-only placeholders** the prose genuinely references
  (e.g. `<ami-id>` where the markdown tells the user to look up their own
  AMI even though the YAML ships a concrete example) — reword or keep.
- Some are **stale spellings** of placeholders the YAML carries under a
  slightly different name (e.g. `<private-subnet-a/b-resource-name>` vs two
  literal `<private-subnet-a-resource-name>`/`-b-` entries) — reconcile.

## Reproduction sweep (run from `apis/dev/planton/provider/`)

```python
import re, pathlib
root = pathlib.Path('.')
for md in root.rglob('v1/presets/*.md'):
    yaml_file = md.with_suffix('.yaml')
    if not yaml_file.exists(): continue
    md_ph = set(re.findall(r'`(<[^>]+>)`', md.read_text()))
    yaml_ph = set(re.findall(r'(<[^>]+>)', yaml_file.read_text()))
    phantom = md_ph - yaml_ph
    if phantom:
        print(f"{md.relative_to(root)}: {sorted(phantom)}")
```

Remember every fix must land in BOTH copies: the `apis/.../presets/*.md`
source and its `site/public/docs/catalog/.../presets/*.md` mirror.

## Resolution

Fixed in `b7dc65b473` (`v0.5.100`): `pkg/presetvalidity` refuses a guide row that names a placeholder its manifest lacks (rule `phantom-placeholder`, never baselined), and every preset guide in the catalog was corrected against its manifest. Pinned by `TestPresetValidityGate`.
