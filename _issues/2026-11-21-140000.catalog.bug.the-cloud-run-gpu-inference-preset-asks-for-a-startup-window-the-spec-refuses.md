# The Cloud Run GPU inference preset asks for a startup window the spec refuses

**Area**: `catalog/gcp/gcpcloudrun/presets/03-gpu-inference.yaml`.
**Type**: bug.

## What a platform engineer sees

A developer who starts from the GPU inference preset gets a manifest that fails validation before anything deploys: "the startup window (failure_threshold × period_seconds, defaults 3 × 10) cannot exceed 240 seconds". The preset's startup probe sets `periodSeconds: 10` and `failureThreshold: 30`, a 300-second window, while Cloud Run caps a startup probe at 240 seconds and the spec's rule refuses anything longer.

## How it was found

Every manifest of the GCP kinds a proof session touched was validated offline with `planton validate`; this preset was the one real failure. It predates that session: the preset file is unchanged on `main`.

## The behaviour wanted

The preset validates and deploys: a startup window of at most 240 seconds (for example `failureThreshold: 24` at `periodSeconds: 10`), with the preset's sidecar explaining that a model that takes longer to load needs a smaller image, a warmer start (minimum instances), or loading after the probe passes. A mechanical net would also catch the class: a test that validates every committed preset of every kind.
