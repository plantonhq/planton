# The provider sends a manual instance count under AUTOMATIC worker pool scaling

**Area**: `catalog/gcp/gcpcloudrunworkerpool`, upstream `google_cloud_run_v2_worker_pool` (both the Google provider and the beta provider Pulumi bridges).
**Type**: bug, upstream.

## What a platform engineer sees

A worker pool with `scaling.scalingMode: AUTOMATIC` can't be created: the provider always sends `scaling.manualInstanceCount` (0 when unset), and Cloud Run refuses any manual count under AUTOMATIC: `Error 400: Violation in CreateWorkerPoolRequest.worker_pool.scaling.manual_instance_count: scaling mode must be set to MANUAL.`

## What the catalog does

The spec refuses AUTOMATIC with that reason (`scaling.automatic_not_deployable`); MANUAL pools deploy. The bounds stay modeled because Google's API offers them.

## Fix

Report it upstream (the provider should send the count only in MANUAL mode). Once the pinned provider does, the CEL rule goes, and the GUIDE, README, catalog page and an AUTOMATIC scenario return.
