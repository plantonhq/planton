# A Cloud SQL connection string can't be read from the instance's outputs

**Area**: `catalog/gcp/gcpcloudsql` (outputs)
**Type**: feature, the catalog half. Handed by the burn-down of every reported issue (2026-09-25, `plantonhq/planton#485`).

## What a platform engineer sees

A composition that wants `DATABASE_URL` in Secret Manager must assemble host, database and user by hand, outside the catalog.

## Fix

The instance exports its connection forms: the private IP and the `/cloudsql/<connection_name>` socket path. Composing several outputs into one string is the platform's reference grammar, not this kind's. Post a partly-done comment on `plantonhq/planton#485` when this half ships.
