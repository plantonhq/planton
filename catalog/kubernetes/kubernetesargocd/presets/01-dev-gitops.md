# Dev GitOps preset

The smallest useful Argo CD: the full control plane at chart defaults,
reachable through a port-forward, with the admin password generated by
Argo CD itself at first start. Read it from the
`argocd-initial-admin-secret` Secret (the name and a ready-made
port-forward command land in the outputs), sign in as `admin`,
and point your first Application at a repository — the whole GitOps
loop works from first boot.

Know what the defaults mean here: the Redis running next to the
control plane is a disposable cache (losing it costs a re-sync, never
state — everything real lives in CRs and your Git history), dex runs
but does nothing until SSO connectors are declared, and the server
serves its own self-signed certificate, which is fine for a
port-forwarded dev loop.

Change first: when this instance outlives the dev loop, declare `sso`
(direct OIDC or dex connectors) and an `rbac` policy, then disable the
local admin — and compose real exposure from KubernetesIngress or a
Gateway kind over the exported `server_service` handle, setting
`server.insecure` so TLS terminates at the edge.

See [01-dev-gitops.yaml](./01-dev-gitops.yaml) for the manifest.
