# KubernetesAgentSandbox Terraform Module

This module creates one namespaced agent-sandbox `Sandbox` through `kubectl_manifest` (alekc/kubectl). It is generated by `planton tofu generate-module KubernetesAgentSandbox`; never edit its `.tf` files by hand, regenerate them. A drift test in `pkg/iac/tofu/generators` fails when the committed files and the generator disagree.

The converter hands the module the manifest's spec with its upstream keys, null fields pruned, 64-bit integers as numbers, and references resolved to plain strings. The module routes the envelope to the object's metadata (`namespace`, and the spec's `labels` and `annotations` under Planton's identity labels) and passes everything else to the custom resource's spec verbatim.

## Prerequisites

- The agent-sandbox controller and its `Sandbox` definition on the cluster (see the `KubernetesAgentSandboxController` kind). `kubectl_manifest` needs no cluster connection at plan time, so the sandbox can be planned before the definition exists.
- The target namespace (see `KubernetesNamespace`).

## Usage

```bash
planton tofu apply --manifest agent-sandbox.yaml
```

## Outputs

| Output | Description |
|--------|-------------|
| `sandbox_name` | Name of the created Sandbox (equals `metadata.name`); its pod and headless Service share it |
| `namespace` | Namespace the Sandbox was created in |

## Import

An existing Sandbox imports with the ID `agents.x-k8s.io/v1beta1//Sandbox//<name>//<namespace>` (see `../import-map.yaml`).
