# KubernetesAgentSandboxTemplate Terraform Module

This module creates one namespaced agent-sandbox `SandboxTemplate` through `kubectl_manifest` (alekc/kubectl). It is generated by `planton tofu generate-module KubernetesAgentSandboxTemplate`; never edit its `.tf` files by hand, regenerate them. A drift test in `pkg/iac/tofu/generators` fails when the committed files and the generator disagree.

The converter hands the module the manifest's spec with its upstream keys, null fields pruned, 64-bit integers as numbers, and references resolved to plain strings. The module routes the envelope to the object's metadata (`namespace`, and the spec's `labels` and `annotations` under Planton's identity labels) and passes everything else to the custom resource's spec verbatim.

## Prerequisites

- The agent-sandbox controller and its extension definitions on the cluster (see the `KubernetesAgentSandboxController` kind, extensions on). `kubectl_manifest` needs no cluster connection at plan time, so the template can be planned before the definition exists.
- The target namespace (see `KubernetesNamespace`).

## Usage

```bash
planton tofu apply --manifest agent-sandbox-template.yaml
```

## Outputs

| Output | Description |
|--------|-------------|
| `sandbox_template_name` | Name of the created SandboxTemplate (equals `metadata.name`), which warm pools reference |
| `namespace` | Namespace the SandboxTemplate was created in |

## Import

An existing SandboxTemplate imports with the ID `extensions.agents.x-k8s.io/v1beta1//SandboxTemplate//<name>//<namespace>` (see `../import-map.yaml`).
