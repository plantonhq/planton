# KubernetesPrometheusRule Terraform Module

This module creates one namespaced prometheus-operator `PrometheusRule` through `kubectl_manifest` (alekc/kubectl). It is generated by `planton tofu generate-module KubernetesPrometheusRule`; never edit its `.tf` files by hand, regenerate them. A drift test in `pkg/iac/tofu/generators` fails when the committed files and the generator disagree.

The converter hands the module the manifest's spec with its upstream keys, null fields pruned, and references resolved to plain strings. The module routes the envelope to the object's metadata (`namespace`, and the spec's `labels` and `annotations` under Planton's identity labels) and passes everything else to the custom resource's spec verbatim.

## Prerequisites

- The prometheus-operator CRDs on the cluster (see the `KubernetesKubePrometheusStack` kind). `kubectl_manifest` needs no cluster connection at plan time, so the rule can be planned before the CRDs exist.
- The target namespace (see `KubernetesNamespace`).

## Usage

```bash
planton tofu apply --manifest prometheus-rule.yaml
```

## Outputs

| Output | Description |
|--------|-------------|
| `prometheus_rule_name` | Name of the created PrometheusRule (equals `metadata.name`) |
| `namespace` | Namespace the PrometheusRule was created in |

## Import

An existing PrometheusRule imports with the ID `monitoring.coreos.com/v1//PrometheusRule//<name>//<namespace>` (see `../import-map.yaml`).
