# KubernetesGkeComputeClass Terraform Module

This module creates one cluster-scoped GKE `ComputeClass` through `kubectl_manifest` (alekc/kubectl). It is generated by `planton tofu generate-module KubernetesGkeComputeClass`; never edit its `.tf` files by hand, regenerate them. A drift test in `pkg/iac/tofu/generators` fails when the committed files and the generator disagree.

The converter hands the module the manifest's spec with its upstream keys, null fields pruned, and references resolved to plain strings. The module routes the envelope to the object's metadata (the spec's `name` as the object's name, and its `labels` and `annotations` under Planton's identity labels) and passes everything else to the custom resource's spec verbatim.

## Prerequisites

- A GKE cluster. GKE serves the ComputeClass definition, so nothing is installed first. `kubectl_manifest` needs no cluster connection at plan time.

## Usage

```bash
planton tofu apply --manifest compute-class.yaml
```

## Outputs

| Output | Description |
|--------|-------------|
| `compute_class_name` | Name of the created ComputeClass (the spec's `name`) |

## Import

An existing ComputeClass imports with the ID `cloud.google.com/v1//ComputeClass//<name>` (see `../import-map.yaml`).
