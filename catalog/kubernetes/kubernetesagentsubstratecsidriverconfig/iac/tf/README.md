# KubernetesAgentSubstrateCsiDriverConfig Terraform Module

This module creates one cluster-scoped Agent Substrate `CSIDriverConfig` through `kubectl_manifest` (alekc/kubectl). It is generated by `planton tofu generate-module KubernetesAgentSubstrateCsiDriverConfig`; never edit its `.tf` files by hand, regenerate them. A drift test in `pkg/iac/tofu/generators` fails when the committed files and the generator disagree.

The converter hands the module the manifest's spec with its upstream keys and null fields pruned. The module routes the envelope to the object's metadata (`name`, and the spec's `labels` and `annotations` under Planton's identity labels) and passes everything else to the custom resource's spec verbatim.

## Prerequisites

- Agent Substrate on the cluster (see the `KubernetesAgentSubstrate` kind). `kubectl_manifest` needs no cluster connection at plan time, so the config can be planned before the definition exists.
- The CSI driver running on the cluster; this config registers it, it does not install it.

## Usage

```bash
planton tofu apply --manifest csi-driver-config.yaml
```

## Outputs

| Output | Description |
|--------|-------------|
| `driver_name` | The driver's name (also the config's name), which a StorageClass names as its provisioner |

## Import

An existing CSIDriverConfig imports with the ID `ate.dev/v1//CSIDriverConfig//<name>` (see `../import-map.yaml`).
