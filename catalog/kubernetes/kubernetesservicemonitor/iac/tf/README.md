# KubernetesServiceMonitor Terraform Module

This module creates one namespaced prometheus-operator `ServiceMonitor` through `kubectl_manifest` (alekc/kubectl). It is generated by `planton tofu generate-module KubernetesServiceMonitor`; never edit its `.tf` files by hand, regenerate them. A drift test in `pkg/iac/tofu/generators` fails when the committed files and the generator disagree.

The converter hands the module the manifest's spec with its upstream keys, null fields pruned, and references resolved to plain strings. The module routes the envelope to the object's metadata (`namespace`, and the spec's `labels` and `annotations` under Planton's identity labels) and passes everything else to the custom resource's spec verbatim.

## Prerequisites

- The prometheus-operator CRDs on the cluster (see the `KubernetesKubePrometheusStack` component). `kubectl_manifest` needs no cluster connection at plan time, so the monitor can be planned before the CRDs exist.
- The target namespace (see `KubernetesNamespace`).

## Usage

```bash
planton tofu apply --manifest service-monitor.yaml
```

## Outputs

| Output | Description |
|--------|-------------|
| `service_monitor_name` | Name of the created ServiceMonitor (equals `metadata.name`) |
| `namespace` | Namespace the ServiceMonitor was created in |

## Import

An existing ServiceMonitor imports with the ID `monitoring.coreos.com/v1//ServiceMonitor//<name>//<namespace>` (see `../import-map.yaml`).
