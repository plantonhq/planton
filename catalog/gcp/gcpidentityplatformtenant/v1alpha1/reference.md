**Guide**: [GUIDE.md](../GUIDE.md) -- authored operational judgment for this kind: conventions, trade-offs, and what pairs well with it.

GcpIdentityPlatformTenantSpec defines one Identity Platform TENANT — an
isolated user pool with its own sign-in configuration and identity
providers, inside a project whose GcpIdentityPlatformConfig has
multi_tenant.allow_tenants enabled. Tenants are how one project serves
multiple customer organizations (B2B SaaS) with separated users,
providers, and policies.

The tenant ID is generated by GCP at create time (never chosen here) —
read it from this resource's tenant_id output. Unlike the project
config, tenants are fully deletable.

The three identity-provider lists compose the tenant-scoped IdP config
resources, mirroring the project-level shapes with the API's own
tenant-level differences (SAML sp_config and OIDC display_name are
required here; OIDC response_type does not exist at tenant level).

## Example

```yaml
apiVersion: gcp.planton.dev/v1alpha1
kind: GcpIdentityPlatformTenant
metadata:
  name: my-sample-tenant
spec:
  # GCP project containing the tenant. Its GcpIdentityPlatformConfig
  # must set multiTenant.allowTenants: true — the tenant API rejects
  # creation otherwise. Omit to use the provider's default project.
  projectId:
    value: my-gcp-project-123

  # Human-readable tenant name (e.g. the customer organization) — the
  # ONLY naming input. The tenant's resource ID is server-generated;
  # read it from the tenant_id output.
  displayName: acme-corp

  # Whether users can sign up with email/password in this tenant.
  allowPasswordSignup: true

  # Whether users can sign in via emailed magic link (passwordless).
  enableEmailLinkSignin: false

  # The tenant-wide kill switch: when true, ALL authentication in this
  # tenant is disabled and existing sessions stop refreshing.
  disableAuth: false

  # Restrictions on what client apps can do against this tenant through
  # the Identity Toolkit API directly.
  clientPermissions:
    # When true, accounts are created only by your backend (admin SDK).
    disabledUserSignup: false
    # When true, account deletion happens only through your backend.
    disabledUserDeletion: false

  # Well-known identity providers enabled for THIS tenant. clientId and
  # clientSecret come from each provider's own developer console —
  # consent-screen OAuth clients have no programmatic creation path.
  defaultSupportedIdps:
    # idpId is one of the ten canonical values (apple.com, facebook.com,
    # gc.apple.com, github.com, google.com, linkedin.com, microsoft.com,
    # playgames.google.com, twitter.com, yahoo.com). Immutable.
    - idpId: google.com
      clientId: 000000000000-placeholder.apps.googleusercontent.com
      # Managed secret — stored as a reference, resolved at deploy.
      clientSecret: GOCSPX-placeholder

  # Custom OIDC identity providers for this tenant. Names must start
  # with "oidc." and are immutable. Tenant-level differences from the
  # project level: displayName is REQUIRED, and there is no responseType.
  oauthIdpConfigs:
    - name: oidc.corp-sso
      # Required at tenant level.
      displayName: Corporate SSO
      # Where Identity Platform fetches the provider's discovery document.
      issuer: https://accounts.example.com
      clientId: corp-sso-client
      # Managed secret; needed when the provider exchange uses a code flow.
      clientSecret: placeholder-oidc-secret

  # Inbound SAML identity providers (enterprise SSO) for this tenant.
  # Names must match saml.<slug> (lowercase start, alphanumeric end) and
  # are immutable.
  inboundSamlConfigs:
    - name: saml.okta-prod
      displayName: Okta (Production)
      idpConfig:
        # Both values come from the IdP's metadata XML.
        idpEntityId: http://www.okta.com/exkexample
        ssoUrl: https://example.okta.com/app/example/sso/saml
        # Whether to sign outbound authentication requests.
        signRequest: false
        # The IdP's public signing certificates (PEM) — not secrets.
        idpCertificates:
          - x509Certificate: |
              -----BEGIN CERTIFICATE-----
              MIIC...placeholder...
              -----END CERTIFICATE-----
      # Required at tenant level — BOTH fields (the API's own rule;
      # optional at the project level).
      spConfig:
        # Where the IdP posts SAML responses — must be https://.
        callbackUri: https://app.example.com/__/auth/handler
        # This tenant's SP entity ID, as registered with the IdP.
        spEntityId: app-example-com

  # ONE switch governs the tenant AND its composed IdP configs:
  # DELETE (default; removes the tenant with ALL its users —
  # unrecoverable), PREVENT (destroy fails), or ABANDON.
  deletionPolicy: DELETE
```
