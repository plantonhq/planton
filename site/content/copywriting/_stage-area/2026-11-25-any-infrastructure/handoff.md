# Handoff: ask your coding agent for any infrastructure

**Route:** `/`, Home's third section (`#infrastructure`), between the first app and the close.

**Where the copy is:** `src/data/homepage.ts`. `HOMEPAGE.infrastructure` holds the heading, the intro (ch 2, proof: the agent line), the next step (ch 8) and the picker's label. `AGENT_RUNS` holds one record per cloud (AWS, Google Cloud, Azure): the ask excerpted with marked ellipses, the set's main file verbatim, the check the agent ran, the table of kinds deployed and torn down in a real account (ch 10, the proving record), the check a reader can run, and the reach line (850+ from `platform-stats.ts`). The clouds and the default are `src/data/clouds.ts`.

**The argument:** after one prompt reaches a running app, the visitor wants to know what happens when the app needs more. Their coding agent picks from Planton's catalog and writes a manifest, checked before anything exists; it never writes the Terraform or Pulumi, because the module that deploys each kind is already written, in the open, and was deployed and torn down in a real account of that cloud. The page proves it with what a real agent wrote, on the visitor's own cloud.

**What the cold reads and the founder changed:** see `draft-1.md`.
