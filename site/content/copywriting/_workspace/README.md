# Copywriting Workspace

The drop zone for the materials a copy change starts from: meeting transcripts, advisory feedback, research notes, screenshots. Everything here is gitignored except this file. A session reads what is here, drafts in `../_stage-area/`, and clears the workspace when the change is recorded.

PDFs are converted to Markdown first: `python3 content/copywriting/_rules/pdf_converter/convert_pdf.py` (see that folder's README).
