# Review captures

The pixels an independent review graded, kept so the next review has a before set. One dated folder per review round that changed a verdict; the capture harness (`scripts/capture-pages.mjs`) produced every file at a fixed width under a virtual clock, so two captures of the same build are byte-identical and a difference is a change in the page.

Only the 1280-wide captures of the pages under review are kept here; the harness regenerates the rest in a minute. Read the verdicts in the session changelogs of the company repository.
