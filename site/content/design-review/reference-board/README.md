# Reference board

Captures of developer-tool landing pages the independent reviewer holds planton.ai's pages against. Each folder carries one first-screen capture at 1280 wide and a README naming the one or two moves that reference is held to. The board is a baseline the page must exceed, never a ceiling: the reviewer asks whether the page makes each move, exceeds it, or omits it.

Captures are refreshed when a reference redesigns; the moves are what matter, not the pixels. Add a reference only with the moves written down.
