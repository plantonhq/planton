# Every AWS kind gets a glyph of its own, a service wears its Architecture tile, a resource wears its Resource icon, and the logo gate compares drawings, not bytes

## What changed

- **All 205 AWS logos are judged under the logo law.** Before, 105 kinds wore a sibling's icon (ten SageMaker kinds one SageMaker tile, eight API Gateway kinds one gate, eight IAM kinds one IAM tile, five EKS kinds one EKS tile, the subnet and three gateways the VPC's tile, the S3 object set the bucket's), 204 named no provenance, seventeen Bedrock kinds wore hand-drawn gradient tiles in colors AWS does not use, and the official files mixed two icon generations (flat tiles from one package, gradient tiles from an older one). Now no two AWS kinds share a drawing, every file opens with its provenance, every official file is re-sourced from the current asset package (`Asset-Package_07312025`), and every drawn glyph is in AWS's own icon language.
- **A kind that IS an AWS service wears its Architecture Service icon** -- 55 of them, the square tile in the category color with a white glyph, from `Architecture-Service-Icons_07312025`: a VPC, an EC2 instance, a Lambda function, an S3 bucket, an RDS instance and an Aurora cluster, DynamoDB, an EKS cluster, an ECS cluster, an ECR repository, CloudFront, a Transit Gateway, a Client VPN, the REST API Gateway, an SQS queue, an SNS topic, an EventBridge bus, a Kinesis stream, a Firehose, an MSK cluster, a Redshift cluster, an OpenSearch domain, an Athena workgroup, a Glue catalog database, a SageMaker domain, a Step Functions state machine, a KMS key, a Secrets Manager secret, an ACM certificate, a Private CA, a Cognito user pool, a WAF web ACL, GuardDuty, CloudTrail, the Config recorder, an Organization, a Budget, Managed Prometheus, an MWAA environment, CodeBuild, CodePipeline, AppSync, an App Runner service, a Batch compute environment, an Auto Scaling group, EFS and the four FSx file systems, MemoryDB, Neptune, DocumentDB, the serverless ElastiCache.
- **A kind that IS an AWS resource the package draws wears its Resource icon** -- 47 of them, a glyph in the category color on a transparent ground, from `Resource-Icons_07312025`: the application and network load balancers (each its own, so an ALB and an NLB never read as one), the internet and NAT gateways, the VPC endpoint, the peering connection, the network ACL, the Elastic IP, the hosted zone, the Resolver endpoint, firewall, and query log, the Cloud Map namespace, the Redis and Memcached caches, the RDS proxy, the EBS volume and snapshot, the lifecycle policy, the S3 directory, table, and vector buckets and the object, the backup vault, plan, framework, report plan, and restore testing plan, the CloudWatch alarm, log group, and canary, the CloudTrail Lake store, the EventBridge rule, pipe, and scheduler, the ECS service, the SageMaker model and notebook, the SES identity, the organization account and unit, the Transit Gateway attachment, and the five Systems Manager kinds (a parameter, a document, an association, a maintenance window, a patch baseline). **Since the July 2025 package these are single files that read on both themes**; the pre-2025 packages shipped them as light/dark monochrome pairs, which the law now names as the form that cannot be worn (below).
- **Everything else is Planton-drawn in the resource form** -- 102 kinds on the 48 grid in the category's one color, no tile, so a drawn child stands beside its official siblings as one family. Twenty-three pre-law hand-made tile glyphs that already said the right thing were kept and converted to the form (the tile dropped, the white recolored, the drawing cropped; three tiles wearing colors AWS does not use -- an older S3 green, two blues -- moved to the category color); seventy-nine are new. The vocabulary: a listener is a port door with an inbound arrow, a listener rule a fork, a target group three targets bracketed; the HTTP API a light gate with one route through it and each custom domain a name tag on its gate, a VPC link a cable from the gate into a network box, a usage plan a meter over a key; a launch template a machine on a template sheet, a security group a shield around a machine, a subnet a partition of the network box, an egress-only gateway a gateway with one outbound arrow; an IAM role a badge lying in a tray, a user a person with a key, a policy a sheet of allow and deny marks, an instance profile a badge clipped to a machine, the OIDC and SAML providers a federation door with a token or an assertion passing through; the Cognito client an app window with a person signing in, the provider a person arriving through a door, the resource server a server with its scopes; every Bedrock kind builds on the model spark -- with a speech tail for an agent, behind a shield for a guardrail, on a tuning dial for a custom model, routed across two regions for an inference profile, writing log lines, beside indexed documents for a knowledge base, behind an opened latch for model access, inside a running-process frame for the AgentCore runtime, with a stack of remembered turns, a token in a locked box, a wrench for tools, a checklist for evaluation; a SageMaker endpoint a served model answering a request, a feature group a table of columns, a pipeline steps chained with a check, the model registry versions on a shelf, the MLflow server and app a run chart on a server and in a window; the Redshift and MSK serverless kinds their store and their pipes over a dashed floor with no nodes beneath; and a settings kind a gear beside the thing it configures.
- **The gate compares drawings, not bytes.** `shared-glyph` hashed the whole file, and the very edit this change makes to 205 files -- a `<desc>` naming each kind's provenance -- would have made two copies of one icon hash as two glyphs the moment each copy received its line. `glyphHash` now strips `<desc>`, `<title>`, comments, and whitespace before hashing; a new deliberate red proves a copied icon under its own `<desc>` still fails at both kinds by name, and the baseline did not move by one entry when the hashing changed (the proof that it changed nothing already judged). Stated in the package comment, rule 021's gate table, and `architecture/catalog-kind.md`.
- **The law learns two things.** An official icon is worn only when ONE file of it reads on both a light and a dark plinth -- a catalog logo is one CDN-served file an image element cannot re-theme, so a light/dark pair (AWS's General Icons, its pre-2025 Resource icons) cannot be worn unaltered, and recoloring is the alteration every provider forbids. And where a provider's own resource icons set a grid, drawn glyphs draw on it (AWS on 48, one tone) instead of the shared 24 grid, so drawn and official read as one set. Rule 021 carries AWS's brand-terms reading, both icon forms, the category palette, and the grid; the update rule's replacement clause names AWS.
- **The contact sheet takes the washes it is handed.** `tools/catalog-logo-sheet` gains `-washes` (`<name>=<paper>/<tint>` entries separated by `;`), defaulting to its two neutral washes. A set judged before its kinds have diagram cards has no plinth to be tried on, so the platform supplies its nine family washes at the plinth's own alpha and the glyph is judged on every plinth it could ever wear -- while the tool itself keeps knowing no family, which is the boundary its comment already drew. The parser has its first tests.
- **AWS joins the judged-provider pin.** `judgedProviders` is `gcp, cloudflare, kubernetes, auth0, openfga, aws`; its 309 baseline entries are gone (204 provenance, 105 shared) and nothing else in the baseline moved. Copying the VPC tile onto the subnet under its own `<desc>` fails the gate and the pin at both kinds by name.

## Why

AWS is the provider most customers draw first, and its diagram said "S3" ten times for ten SageMaker things and "VPC" for a subnet, a NAT, and two gateways alike. AWS offers exactly the two icon forms a diagram needs -- a tile for a service, a glyph for a resource -- to customers and partners for this use, and its current package finally ships the resource glyphs as one colored file each; using both, unaltered, gives every AWS kind the icon an AWS engineer already knows where one exists, and a drawing in the same hand where one does not. The gate change is the kind of defect that ships silently: the law asked every file to describe itself, and the description would have become the thing that told two copies apart.

## How to check

```bash
go test ./pkg/cataloglogo/ ./pkg/anatomy/ ./tools/catalog-logo-sheet/   # green, AWS absent from the baseline and pinned
grep -L '<desc>' catalog/aws/*/logo.svg                                  # prints nothing: every file names its provenance
grep -l 'Gradient' catalog/aws/*/logo.svg                                # prints nothing: one icon generation, no drawn gradients
go run ./tools/catalog-logo-sheet/ -provider aws                         # then open the HTML it names; -washes "<name>=<paper>/<tint>;..." for the family washes
```
